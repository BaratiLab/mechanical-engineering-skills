# Review checklists

## Concept / SRR
- Problem statement, users, use cases
- Requirements baselined and measurable
- ≥ 2 concepts compared on a weighted decision matrix
- Key risks and the plan to retire each

## PDR
- Architecture and interfaces defined (ICD)
- Key analyses done to first order (loads, stress margins, thermal, tolerance stack)
- Make/buy decisions and long-lead items identified
- DFMEA started; High-AP items have actions
- Preliminary BOM and cost target vs. estimate
- Test and verification plan

## CDR
- Drawings at release quality, GD&T checked
- All analyses final, with margins ≥ requirement
- DFMEA actions closed or accepted
- DFM review with the chosen suppliers done
- BOM costed with quotes
- Prototype test results correlated with analysis
- Production / assembly plan and inspection plan

## Production readiness
- PFMEA, control plan, first-article inspection
- Supplier PPAP / approvals
- Work instructions, fixtures, gauges validated
- Service and spares plan
