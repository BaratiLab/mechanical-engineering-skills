# Calc report conventions

- Number every equation (Eq. 1, 2, …), table, and figure.
- Inputs table columns: Symbol | Description | Value | Unit | Source.
- Assumption format: **A3.** Bolt threads excluded from the shear plane. *Conservative if threads are in the plane: no; verify on drawing.*
- Substitution line: show values with units, e.g. τ = 12 000 N / (4 × 50.27 mm²) = 59.7 MPa.
- Margin of safety: MS = Allowable / (FoS × Applied) − 1. Report to 2 decimals.
- Sign-off block: Prepared / Checked / Approved, with name, signature, and date, each left blank for humans.
- Revision history: Rev | Date | Description | By.
- Never present an LLM-derived value as checked. The "Checked by" line is for a qualified engineer.
